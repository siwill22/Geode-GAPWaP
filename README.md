# Paleomagnetic Poles

Torsvik et al. (2012) virtual geomagnetic poles, their sample sites and the modelled GAPWaP, on the Torsvik & Cocks 2017, Scotese and Merdith 2021 Reconstruction Models.

Generated by [Geode](https://github.com/siwill22/Geode)'s viewer generator.
See `recipe.json` in this repo for exactly what was requested.

## Data

- Comparing Reconstruction Models (switch via dropdown):
  - **Torsvik & Cocks (2017)** (`torsvikcocks2017`) -- coastlines only, no boundary topology
  - **Scotese 2008** (`scotese`) -- coastlines only, no boundary topology
  - **Merdith et al. 2021** (`merdith2021`)

The data ships with this repo in `public/archive/` (~33 MB): the three
Reconstruction Models' coastlines, static polygons, rotations and (Merdith
2021) plate boundaries, plus the pole set exported for each. It is a trimmed
copy of Geode's packed archive, produced by Geode's `prep/prep_reconstruction.py`
and `prep/prep_paleomag.py`; to update it, regenerate there and copy the
same files across.

Torsvik & Cocks 2017 is shown anchored on plate 1, not 0 (`anchorPlates` in
`recipe.json`).
